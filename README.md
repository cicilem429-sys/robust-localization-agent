# 智能体驱动的鲁棒众包定位方法探索

《人工智能与数学》课程项目。选题来自《HarmonyOS难题发布-第七期》第1页“基于非线性优化的众包离线高精度位置聚合难题”。当前研究静止目标的合成数据子问题。

## 具体研究问题

已知上报设备位置 a_i 和对目标的距离估计 d_i，估计目标二维坐标 x。普通最小二乘最小化 sum_i (||x-a_i||_2-d_i)^2。当部分观测有较大误差，或上报设备集中在一个方向时，估计可能显著偏离真值。

本项目研究：在正常场景精度约束下，智能体能否依据实验反馈选择损失函数、尺度和后续权重策略，降低异常场景的定位误差？

鲁棒目标为 sum_i C^2 rho((||x-a_i||_2-d_i)^2/C^2)。当前所有观测权重均为1。Huber、soft-L1 和 Cauchy 都是已有方法。拟探索的贡献是有精度约束、失败案例反馈和独立核验的实验决策策略，其新颖性与效果尚待检验。

## 复现离线原型

使用 Python 3.11 或更新版本。命令在本项目目录内运行。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python experiment.py --output results
python verify.py
```

Windows 激活命令为 `.venv\Scripts\activate`。重新运行会覆盖 results 下的同名离线实验文件，需保留旧实验时使用 `--output results/run-002`。数据与结果以米为单位。

## 数据与实验约定

开发与测试各90例，每种场景各30例，每例12个上报设备。场景为干净观测、25%距离异常、25%距离异常加不良几何。目标坐标在 [-10,10]^2 内生成，真实距离15至45米，正常测距噪声标准差1米，上报位置噪声标准差0.5米。异常距离增加15至30米。不良几何中观测方向集中，角度标准差0.08弧度。

所有方法均使用4个相同初值，每个初值 max_nfev=100。候选损失为 linear、huber、soft_l1、cauchy，离线尺度为1、3、8米。规则控制器和随机搜索各评估6个候选。这是候选次数相同，不代表总运行时间或内部求解次数相同，日志另存 nfev 和耗时。

CEP90 为每个场景定位误差的经验90%分位数。选择目标为三种场景 CEP90 的均值，加上正常场景超过基线1.10倍部分的10倍罚项。该罚项是软约束，必须另外核验精度约束是否满足。三场景均值不是混合数据整体 CEP90。

## 首次独立测试结果

| 方法 | 干净观测 CEP90/m | 异常观测 CEP90/m | 不良几何 CEP90/m | 三场景均值/m |
| --- | ---: | ---: | ---: | ---: |
| 普通最小二乘 | 1.041 | 17.098 | 25.876 | 14.672 |
| 固定 Huber，C=3 | 1.041 | 3.432 | 14.358 | 6.277 |
| 反馈选择 Cauchy，C=3 | 1.184 | 1.415 | 10.119 | 4.239 |
| 随机选择 Cauchy，C=1 | 1.368 | 1.513 | 9.551 | 4.144 |

反馈方案改善了异常观测误差，但三场景均值没有超过随机搜索。反馈方案干净场景较最小二乘退化约13.7%，也没有在测试集满足10%退化限制。只有一个数据种子、每场景30例，不能作统计优势判断。这些失败是下一轮智能体研究的输入。

方案选择只使用开发集。首次测试结果现已用于分析，后续正式研究应冻结方法后生成新测试集，避免反复使用该测试集造成间接泄漏。

## 文件说明

- `experiment.py`：数据、求解、离线反馈控制与随机对照。
- `evaluate_candidate.py`：外部研究智能体的开发集工具。
- `start_research.py`：上游控制器接入启动器。
- `verify.py`：无噪声恢复、分割种子、选优记录和指标重算核验。
- `results/`：首次实际运行记录、测试数据与结果。
- `docs/`：研究任务、口头稿、GitHub搭建说明及进展PDF。

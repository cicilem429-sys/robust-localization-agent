# 约2分钟进展汇报稿

老师好，我的选题是“面向异常观测的众包定位：智能体驱动的鲁棒非线性优化方法探索”。选题来自 HarmonyOS 难题材料中的第一题。

具体来说，一个丢失设备的位置未知，周围多个设备会上报自身位置，以及根据蓝牙信号推算出的距离。我要研究如何利用这些观测估计丢失设备的二维坐标。难点是部分观测可能有较大的误差，而且上报设备集中在同一方向时，定位也容易不稳定。

我先把范围限定为静止目标和合成数据，建立非线性最小二乘模型。接下来让研究智能体提出损失函数、尺度或权重的修改方案，调用 Python 数值工具检验，再根据结果决定下一轮实验。重点研究在正常场景精度约束下，能否改善异常场景的定位，而不只是不断降低一个指标。

目前已完成数据生成、数值求解和六轮规则反馈实验，保留了每轮方案与结果，并设置了固定方法和同候选次数随机搜索作对照。首次测试中，反馈选出的鲁棒方法改善了异常观测误差，但综合表现没有超过随机搜索，正常场景也出现退化。这说明需要继续检查策略选择的依据与约束。

当前完成的是无需模型密钥的反馈原型，还没有完成大模型智能体的真实运行。我已经准备了老师开源研究控制器的任务和工具接入。下一步运行真实智能体、保存模型与工具交互记录，并增加多种子实验、消融和新的独立测试。最终提交代码、迭代日志和 PDF 报告，不把模拟结果当作已经解决工业原题。

# 可能被追问的5个问题

**为什么属于数学研究？** 未知量是二维向量，目标函数由欧氏距离残差构成，涉及非线性优化、鲁棒统计、几何可观测性与误差分析。

**哪里是未解决的问题？** 来源是材料提出的工程难题。课程子问题是探索有正常精度约束的智能体实验决策方法。静止定位和鲁棒损失本身已有大量研究，不能称它们为新的公开数学猜想。需要向老师明确本项目采用“工程难题的子问题与方法探索”路线。

**智能体和普通调参有什么区别？** 最终要求模型根据具体失败案例提出可解释假设、调用工具验证并修正。还需与随机搜索对照，证明这种决策过程有没有实际价值。当前规则控制器只是工具闭环原型。

**新方法是什么？** 拟探索结合正常场景精度约束、残差反馈和几何诊断的策略选择方法。Huber与Cauchy不是新方法，具体新策略尚待模型探索、实现和文献检查。

**为什么不直接用液态神经网络？** 当前先研究可解释且数据需求少的二维优化问题，避免同时引入网络训练、数据不足和智能体搭建三类困难。如后期需要，可以把学习权重作为扩展，必须比较已有基线。

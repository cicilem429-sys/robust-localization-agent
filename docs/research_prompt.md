# 研究任务：异常观测下的众包二维定位

源问题为《HarmonyOS难题发布-第七期》第1页，当前限于静止目标、合成数据。
研究问题：在正常场景精度约束下，如何用实验反馈选择鲁棒损失与尺度，降低异常观测与不良几何场景的定位误差？

先阅读项目 README.md、experiment.py 和 results/iterations.jsonl。
开发集已包含真值，因此开发工具可以计算定位误差。实际部署时不能访问未知位置真值。
不得读取 results/test_cases.json 或 results/summary.json 中的测试结果来决定方案。
现有测试集已供第一次进展汇报使用，不得把它作为后续正式盲测集。后续必须在方案冻结后生成新种子的测试集。

每轮应完成：提出假设与理由；调用数值工具；比较开发指标；解释失败；决定下一轮。
工具：在项目目录下运行 Python evaluate_candidate.py --loss huber --scale 3 --reason "你的研究假设"。
工具仅允许 linear/huber/soft_l1/cauchy 与 [0.5,20] 米尺度，不执行模型生成的任意代码。
大模型承担假设生成、实验计划、反馈解释与记录，数值解由 SciPy 独立计算。
先做6轮。初次研究不修改数据生成器或数值工具。若提出新权重、新损失或几何诊断，写明数学定义与实现计划，等待下一阶段实现。

保存每轮模型输入、模型输出、工具调用、工具输出、验证结论与下一步。
独立核验器应检查：单位、目标函数、初始化、样本量、是否使用测试反馈、数值结果与代码日志是否对应。
比较普通最小二乘、固定 Huber、同候选预算随机搜索，额外报告求解调用数与耗时。
clean 场景 CEP90 不超过平方损失基线的1.10倍为开发集目标，不能仅靠罚函数宣称满足约束。
记录不良几何条件下的失败案例。数值成功状态不等于误差达标。
不宣称 Huber/Cauchy 为新损失，不宣称解决全球最优或工业定位难题。
最终生成研究记录 Markdown，分别列出实验事实、待验证猜想、未解决问题和方法的新颖性检查。
